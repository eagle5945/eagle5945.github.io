# 2026년 하반기 주목할 AI/LLM 트렌드 3선

지난 2026년 하반기 AI/LLM 분야는 '단순히 답을 잘아는' 차원을 넘어, 모델이 **스스로 일을 수행하는 에이전트**로 본격 전환했습니다. 특히 오픈소스·오픈웨이트 모델이 프론티어 모델과의 격차를 크게 줄이면서, 물리·환경을 이해하려는 **월드 모델**까지 다다르는 등 2026년 2분기 기준으로 주목할 만한 흐름이 뚜렷해졌습니다.

## 1. 에이전틱 코딩과 개인 맞춤 에이전트의 일상화

LLM이 '답을 알려주는' 단계를 넘어, 스스로 **웹 브라우징, 툴 호출, 코드 작성 및 수정**까지 수행하는 에이전트가 일상화되고 있습니다.

- **Claude Code, OpenAI Codex**: AI 코딩 에이전트가 브라우저 툴을 내장해 웹사이트 수정, UI 생성, 데이터베이스 쿼리까지 직접 실행
- **OpenClaw**: 개인 전용 에이전트로, 하드웨어 위에서 24/7 백그라운드 운영 (모니터링, 인시던트 대응 등)
- **멀티 에이전트 오케스트레이션**: 하나의 프롬프트로 웹사이트, 슬라이드, 스프레드시트를 만드는 등, 여러 서브-에이전트가 작업을 분담

> "코딩 실력이 없어도 AI 에이전트 덕분에 작동하는 앱을 만들 수 있다"는 평가에서, 이미 Replit이나 Lovable 같은 서비스가 이를 구현 중심에 놓고 있습니다.

## 2. 오픈웨이트 모델이 프론티어를 넘본다

2026년에는 '오픈소스 = 대체재'라는 인식이 깨졌습니다. MoE 아키텍처와 긴 컨텍스트 창을 바탕으로 한 오픈웨이트 모델들이 프론티어 모델과 벤치마크 격차를 크게 줄이고 있습니다.

| 모델 | 파라미터(총/활성) | 컨텍스트 | 특징 |
|------|-------------------|---------|------|
| **GLM 5.2** | 743B | 1,040k 토큰 | 최강 평가 지표 중심 |
| **Kimi K3** | 2.8T (16/896 experts) | 1M 토큰 | 초거대 MoE |
| **DeepSeek-V4-Pro** | 1.6T | 1,040k 토큰 | 오픈 소스 가족 |
| **MiniMax M3** | 428B (23B 활성) | 512k 토큰 | 네이티브 이미지/비디오 입력 |
| **gpt-oss-120b** | 116B | 131k 토큰 | Apache-2.0, 고속 출력 |

- **MoE 구조**로 "총 파라미터는 크지만 활성화되는 파라미터만 선택"하는 방식으로 효율성과 성능을 동시에 끌어올림
- **1M 토큰 이상 초장거 컨텍스트**: 전체 코드베이스, 장문 논문, 다중 세션 메모리 처리 가능
- **gpt-oss-120b**: Apache-2.0 라이선스로 상용 제품에 바로 투입 가능

## 3. 네이티브 멀티모달 → 월드 모델(World Model)

텍스트뿐 아니라 이미지, 음성, 비디오까지 아우르는 **네이티브 멀티모달**이 기본이 되었고, 이제 그 다음에는 **세계를 이해하고 시뮬레이션하는 월드 모델**이 주목받고 있습니다.

- **Gemini 3 / GPT-5 / Claude Sonnet 5**: 텍스트+이미지+비디오 통합 처리. 다이어그램 업로드 → 요소별 질문 → 시각 정보를 참고한 답변
- **Genie 3 (Google DeepMind)**: 실시간 대화형 3D 월드 모델. 이미지 한 장을 보고 영화 같은 새로운 세계를 생성하며, "생성된 세계"는 지속적이고 상호작용 가능
- **Cosmos (NVIDIA)**: 2억 장 이상의 비디오 클립으로 학습한 월드 모델. 텍스트-세계, 이미지-세계, 비디오-세계 생성을 통합. 로봇 및 자율주행 훈련용 시뮬레이션
- **AMI Labs (Yann LeCun)**: 5억 유로 규모 펀딩으로 "텍스트 예측이 아닌 물리 법칙을 이해하는 AI" 구축 추진

> 물리·환경 이해라는 차원에서, 더 이상 "다음 단어를 맞추는" 모델이 아니라 "세계의 법칙을 시뮬레이션하는" 모델 시대로 넘어가고 있습니다.
