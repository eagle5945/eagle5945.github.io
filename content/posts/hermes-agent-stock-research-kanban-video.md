주식 관련 뉴스를 모아 보고서를 만드는 일을 에이전트 하나에 모두 맡기면, **어떤 자료를 근거로 분석했는지** 나중에 확인하기 어렵습니다. [로치의개발일기 영상 「헤르메스 에이전트팀으로 주식 분석 자동화 하기」](https://www.youtube.com/watch?v=y3leLF84MyY)은 SK하이닉스 관련 뉴스를 예시로, 자료 조사와 분석을 서로 다른 Hermes Agent 프로필에 맡기고 칸반 티켓으로 연결하는 과정을 보여줍니다.

이 글은 **영상의 한국어 자막을 바탕으로 재구성한 요약**입니다. 영상 속 설정을 이 글을 작성하며 직접 재현하거나, 보고서의 투자 판단을 검증한 것은 아닙니다.

## 먼저 작업 흐름을 나눕니다

영상이 설명하는 전체 구상은 **뉴스 탐색 → 원문 링크와 자료 정리 → 분석 → 결과물 검토 → 발행 여부 결정**입니다. 자동화에 앞서 사람이 실제로 하는 단계를 적어 두어야 역할과 검수 지점을 정할 수 있다는 설명입니다. 다만 이번 영상에서 실제로 보여주는 범위는 **PDF 보고서 생성까지**이며, 글의 자동 발행은 시연하지 않습니다. [영상 0:35~2:08](https://www.youtube.com/watch?v=y3leLF84MyY&t=35s)

## 준비사항

영상 사례를 직접 응용하려면 Hermes Agent 사용 환경, 별도 작업 폴더, 확인할 뉴스 출처, 리서처·분석가의 역할 구분, 결과물을 검토할 사람이 필요합니다. 아래는 **영상에서 보여준 구성 단계의 요약**이지, 이 글에서 같은 워크플로를 직접 실행해 검증한 절차는 아닙니다.

## 영상의 구성 단계: 역할과 인계 지점 설계

1. **작업 폴더와 자료 출처를 정합니다.** 영상은 별도 프로젝트 폴더를 만들고 네이버 증권의 뉴스 목록과 종목 뉴스 페이지를 조사 대상으로 삼습니다. 실제 운영에서는 접근 가능한 출처인지 확인하고, 기사 제목·발행일·원문 주소를 함께 남기는 편이 좋습니다. [영상 2:11~3:42](https://www.youtube.com/watch?v=y3leLF84MyY&t=131s)
2. **리서처 프로필을 만듭니다.** 리서처에게는 뉴스와 출처를 모으고 분석가가 다시 확인할 수 있도록 정리하는 역할을 줍니다. 영상에서는 프로젝트의 공통 목표를 `AGENTS.md`에 두고, 조사 형식처럼 특정 역할만 필요한 긴 지침은 별도 문서로 분리합니다. [영상 3:55~10:23](https://www.youtube.com/watch?v=y3leLF84MyY&t=235s)
3. **분석가 프로필과 칸반 보드를 준비합니다.** 분석가는 조사 자료를 받아 부족한 근거를 보충하고 보고서를 작성합니다. 영상은 프로젝트 폴더에 연결된 보드를 만들고, 리서처가 작업을 마치면 분석가에게 자료 위치와 핵심 내용을 담은 티켓을 넘기도록 설정합니다. [영상 11:08~16:44](https://www.youtube.com/watch?v=y3leLF84MyY&t=668s)
4. **자료 수집부터 보고서까지 티켓으로 추적합니다.** 리서처가 뉴스 자료를 정리하고 인계 티켓을 만들면 분석가가 이를 받아 결과물을 만듭니다. 영상에서는 분석 결과를 PDF로 만드는 일을 별도 티켓으로 요청하며, 진행 상태·댓글·작업 로그와 최종 파일을 확인합니다. [영상 17:40~23:36](https://www.youtube.com/watch?v=y3leLF84MyY&t=1060s) · [영상 25:56~29:25](https://www.youtube.com/watch?v=y3leLF84MyY&t=1556s)

**영상에서 건질 핵심은 칸반을 단순한 할 일 목록이 아니라 작업 인계와 진행 내역을 추적하는 장치로 쓰는 점**입니다. 조사 담당자가 어떤 자료를 남겼는지, 분석 담당자가 무엇을 확인하고 산출했는지 티켓 단위로 살펴볼 수 있습니다. 다만 티켓과 작업 로그만으로 기사 내용의 진위나 PDF 결론의 정확성이 보장되지는 않습니다. [영상 23:38~25:35](https://www.youtube.com/watch?v=y3leLF84MyY&t=1418s)

## 확인 방법과 실제 적용 시 주의점

- **출처:** 원문 URL, 발행 시점, 인용한 수치의 기준 시점을 보고서에서 역추적할 수 있는지 확인합니다. 기사 원문을 통째로 복제하기보다 필요한 사실을 요약하고 출처를 남깁니다.
- **역할:** 리서처의 수집 결과와 분석가의 해석을 구분합니다. 영상 시연에서는 리서처의 초기 조사 자체가 모두 티켓으로 시작되지는 않았으므로, 운영할 때는 조사 시작부터 티켓을 만드는 방식을 검토할 만합니다.
- **검수:** AI가 만든 투자 시나리오·가격 판단을 검증 없이 게시하거나 거래에 사용하지 않습니다. 발행 전 사람이 원문, 날짜, 계산과 결론의 한계를 확인해야 합니다.
- **환경:** Hermes 버전이나 보드 UI에 따라 메뉴와 설정 방식이 다를 수 있습니다. 실제 구성 전 [공식 프로필 안내](https://hermes-agent.nousresearch.com/docs/user-guide/profiles)와 [칸반 안내](https://hermes-agent.nousresearch.com/docs/user-guide/features/kanban)를 확인하세요.

이 사례는 **투자 추천이나 SK하이닉스의 현재 가치 평가가 아닙니다.** 영상의 사례는 에이전트 간 작업 인계와 진행 내역을 추적하는 구성 예시입니다.
